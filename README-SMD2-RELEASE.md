# SMD 2.0 release candidate — external integration and release gates
## Implemented in preview
- Local browser PDF text extraction with page markers and Indonesian/English Tesseract OCR. Self-hosted assets built from pinned new dependencies; file ≤20 MB, ≤100 pages, ≤15 OCR pages, review required. Long scans need splitting. No PDF/OCR content is sent to a third-party extraction service. Dependency lockfile generation and browser UAT remain required (local npm registry unavailable).
- FIRMS NOAA20 VIIRS NRT area API using server-only FIRMS_MAP_KEY. Admin session and uploaded company polygon required; bounded bbox, point-in-polygon, 1–3 day windows, reviewed snapshot save, opt-in hourly refresh while tab visible, max 24 requests/admin/day. No map key supplied yet; no actual satellite API request verified. Not unattended or a deforestation feed. Hotspots are potential thermal anomalies, not confirmed fires.
- Knowledge Assistant with ranked retrieval and bounded excerpts, explicit user consent, admin-only access, source refs and daily maximum 10 calls/admin. Requires SMD_AI_ENABLED=true, SMD_AI_MODEL (verified catalog candidate openai/gpt-4.1-mini), and AI_GATEWAY_API_KEY or approved Vercel OIDC. Must confirm organizational data handling, ZDR/no-training settings, budget, exact provider options and run synthetic request before enabling. Disabled by default; no company documents transmitted and no credits spent. Keyword search remains usable.
- Existing spatial/media endpoints now require signed-in operator role; API errors avoid exposing credentials. Local screening is preliminary, not legal determination.
- Database security migrations: smd2_close_legacy_anonymous_access_and_fail_closed_admin and smd2_external_provider_daily_request_limits. Existing shared database: 47 public tables with RLS; no anon/public policy on public tables. Legacy group-wide weekly report and plan restricted to all-company approved accounts; writing additionally requires operator role. NDPE company scoped. Admin and unauthorized SQL tests rolled back. Existing security advisor warnings remain; don't treat as full security certification.
## Activation steps
1. Obtain free NASA MAP_KEY at https://firms.modaps.eosdis.nasa.gov/api/map_key/; add as encrypted Preview environment variable FIRMS_MAP_KEY for smd-v2 only. Do not post keys in chat or GitHub. Test one small boundary with non-sensitive test data, verify 0-result and error states, then approve unattended schedule and separate deforestation provider.
2. Approve AI Gateway data governance and costs, configure preview SMD_AI_MODEL, gateway credential or OIDC, then SMD_AI_ENABLED=true. Verify request-level ZDR/no training and response sources with synthetic text. Never set AI key NEXT_PUBLIC.
3. Browser UAT: login admin/assessor, all seven main menus, import a synthetic GeoJSON and PDF digital/scanned in isolated staging or approved test workflow; verify original download, page markers, no external document network traffic, role deny, error and empty states, all buttons, mobile layout, existing workflow regression.
4. Verify independent database backup/restore and review remaining security advisors, dependency lock/audit and public repository confidentiality; no internal evidence or sensitive geometries committed to GitHub.
5. Only after sign-off stage a production build, verify production variables and migrate changes from smd-v2 to main with rollback plan. Current production branch remains unchanged.

- Incomplete local screenings cannot be saved as final risk records. Newly saved preliminary local assessments are classified as unverified in supplier intelligence. Official screening results must match the entered data before saving.
