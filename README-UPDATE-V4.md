# System Monitoring Update V4

New in V4:
- Edit Grievance form
- Automatic grievance due-state badge (On Track / Due Soon / Overdue / Closed)
- Action Plan section
- Add Action
- Edit Action
- Action priority, PIC, target date, status, progress, completion date and remarks
- Automatic action due-state (On Track / Due Soon / Overdue / Completed)
- Action summary cards

Starter mode remains browser-only via localStorage. Existing grievances and updates are preserved in the same browser.

Upload the `app` folder to the root of the GitHub repository and commit the changes. Vercel will redeploy automatically.
