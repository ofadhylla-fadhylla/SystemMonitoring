# GeoWatch disturbance monitoring
- GFW Data API integrated disturbance dataset: https://data-api.globalforestwatch.org/docs ; query geometry, longitude/latitude, alert date, confidence, area__ha (see https://developer.openepi.io/how-tos/integrated-deforestation-alerts-x-global-forest-watch-api). GFW Data API, not retiring GFW Pro API.
- Server-only GFW_API_KEY required; no live key configured. Admin session and explicit per-boundary transmission consent required. Sends geometry only, not names/attributes. Max 31 days, 10k pixels, 12 queries/admin/day. No automatic query when app closed.
- One chosen HGU or supplier polygon layer. Source pixel centers checked locally, deduplicated; summed provider pixel areas are approximate, not clipped overlap or confirmed deforestation. No summing across overlapping snapshots; source date/version/retrieval metadata saved. EUDR date screening is detection date only, not legal proof. NDPE cutoff must be set per approved policy. Before/after imagery review is manual; no automatic historical imagery or land-use classification.
- Review register is append-only per saved snapshot, evidence/PIC/due/status/optional verified area. FK restricts deletion of reviewed layers. No automated field verification or approval role workflow.
- New migration smd2_disturbance_investigation_register_and_gfw_quota on existing shared DB. No test rows persisted. Preview only; UAT and provider verification remain required.
