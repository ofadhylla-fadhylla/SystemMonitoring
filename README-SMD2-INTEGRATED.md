# SMD2 integrated dashboard & attention center
Admin-only new register overview follows the company filter (knowledge is group-wide), month-selectable KPI, findings status, No Buy, traceability links, boundaries and legal register. Existing dashboard retains prior risk weights, now rejects invalid/out-of-range supplier scores and missing certificate dates for active validity counts. Date deadlines use Jakarta calendar days. Attention center uses paginated source reads and includes overdue findings, No Buy, legal expiry and KPI exceptions for administrators; failed source reads show unavailable rather than false zero. In-app notifications refresh while the app is open; no scheduled email or push. No schema changes. PDF/OCR and generative AI remain pending dependency/provider review; satellite feed requires credentials. Browser UAT and independent backup verification remain release gates.
